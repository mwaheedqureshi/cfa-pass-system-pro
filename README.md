# CFA PASS SYSTEM Professional v1.0.0

## Start
1. Extract the ZIP.
2. Double-click `start_server.bat`.
3. Open `http://localhost:8000`.

Alternatively use the VS Code Live Server extension.

## Included
- Markdown lesson engine
- Sidebar and search
- Table of contents
- Progress and dark mode
- Quiz engine with explanations
- Complete Quantitative Methods lesson: Returns of Financial Assets and Instruments

## Add a lesson
Create a Markdown file, add question JSON, and register it in `data/curriculum.json`.
