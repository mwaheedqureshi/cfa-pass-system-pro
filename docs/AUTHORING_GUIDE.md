# Authoring Guide

## Lessons

Use the manifest naming and ordering conventions. Every completed lesson must contain common mistakes, exam tips, a revision sheet, and a 30-second summary. Use GFM tables and existing fenced `formula`, `example`, and `calculator` blocks. Keep explanations original and state assumptions, units, and interpretations.

## Questions

Each question needs a stable ID, valid lesson reference, exactly three choices, one correct index, difficulty, solving time, explanation, three option explanations, tags, and valid formula references. Use either an authorized official outcome or an explicitly independent `scopeStatement`, never both.

## Flashcards

Use a stable ID, valid lesson ID, concise prompt, clear answer, and useful tags. Fronts must be unique and should not duplicate question stems.

## Formulas

Include name, expression, meaning, variables, intuition, worked example, common mistake, related lesson, curriculum mapping, and tags. Disambiguate context-specific variants and verify arithmetic independently.

Run content validation before review. Do not copy provider text or imply unofficial scope statements are official CFA Institute wording.
