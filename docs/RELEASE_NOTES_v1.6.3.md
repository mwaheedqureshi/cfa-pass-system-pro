# v1.6.3 — Official 2027 Quantitative Curriculum Mapping

This is a mapping and migration-design release. It does not authorize lesson, question, flashcard, formula, assessment, route, navigation, or learner-progress behavior changes.

The authorized local 2027 Quantitative curriculum confirms 11 official learning modules. The target application structure retains 12 stable study lessons because official LM7, Estimation and Hypothesis Testing, is represented by an Estimation subdivision and a Hypothesis Testing subdivision.

Private source-backed records now define the official module map, every lesson’s remediation target, and classifications for all 500 Quantitative questions, 500 flashcards, 135 formulas, and 26 interactive tools. Public design documents specify the future manifest, progress migration, and the v1.6.4–v1.6.6 execution sequence.

No migration is executed in this release. In particular, future treatment of `quant-distributions-07` must transfer legitimate legacy distribution evidence to LM6 without completing portfolio LM8, preserve notes and historical analytics, and exclude legacy attempts from portfolio performance.

The repository already contains pre-existing later-facing LM6/LM8 and progress code from earlier development. This release leaves that code unchanged and records it for reconciliation during v1.6.5; its presence is not evidence that remediation or mathematical verification is complete.

Package metadata remains v1.6.2 because project standards do not explicitly require application-version changes for a documentation-only mapping release, and the user prohibited unnecessary public application metadata changes.
